# model-detect 产品宪章 v1.0（冻结基线）

冻结日期：2026-10-19。本文是**产品方向与边界**，不是开发进度表。后续开发不得直接改写本文；功能变更只能写入执行计划。任何试图改变产品目标、适用对象、核心证据原则和非目标的提议，必须单独走用户明确批准的版本化决策（新 v2 文件），保留本文件历史，不能借代码重构暗改方向。

## 一句话定位

**单机、自用、低门槛的 LLM 供应商 API 准入与异常筛查工具**：输入供应商 Base URL、API Key 和声称的模型 ID，选择快速/标准/深入检测，输出协议问题、能力结果、疑似异常及证据充分性，保留中文报告与本地历史。参考 ztest.ai/Cadai 的使用体验，不照搬没有独立校准的“真假百分比”。

## 核心用户与使用场景

仅个人维护者；检查模型中转服务/渠道，客户准入前诊断，复测版本漂移，比较同一模型的不同供应商。无需官方 API、GPU、企业租户、账号体系或公共 SaaS。唯一必须的在线凭据是**待测供应商**的 API Key；纯离线演示及回归不需要任何 Key。API 测试会产生真实费用，运行前显示预计请求与 Token 上界（估计不等于账单硬上限）。

## 稳定输出：四个答案

1. **协议是否正常**：OpenAI Chat Completions 基础 JSON/SSE、tool calls、usage、错误码及模型明确支持的参数。每项依据明确；不支持的参数不按 FAIL 计算。
2. **能力是否符合预期**：以开源原始任务/评分器为主，按数学、指令、代码等独立展示样本数与成绩；快速题只做 Smoke，不作为权威“智商分”。
3. **是否出现异常信号**：混路由、降级、模型行为变化只报告证据/置信局限/复测建议；黑盒测试无法认证模型权重，不宣称“满血”“100% 真模型”。
4. **结果可复核吗**：报告保存模型 ID、请求条件、任务版本、来源、失败和未知原因，支持历史、对照、导出；未实际运行的不得显示通过。

## 首版覆盖模型

GLM-5.3、GLM-5.3-Flash、Kimi-K3、DeepSeek V4、DeepSeek V4.1（以及经来源确认的官方变体/版本化 API 别名）。以官方现行资料校对真实 model ID；**商品称呼不等于 API 名**。每个型号单独小配置，同一通用执行引擎，不建五套子系统。外部发布时使用的是渠道声明模型，不能默认等同实际权重。新版本出现可更新模型目录与来源，不改变产品宪章。

## 三种检测档位

- **Quick**：低成本通用协议、最小能力冒烟；用于先判断“能否接入”。
- **Standard（默认）**：扩充协议、典型任务、有限重复/异常一致性抽查；用于渠道初筛。
- **Deep（显式开启）**：固定版本的开源能力 Benchmark / Kimi 官方原始协议测试（适用时）、更大样本；依赖缺失或成本未知时必须预检并拒绝静默收费。不承诺所有高难、多模态、Agent 评测在 v0.2.0 全面支持。

## 信任规则（不可因赶进度删除）

- 状态为 PASS / FAIL / UNKNOWN / NOT_APPLICABLE（内部可更细）；错误、429、超时、空响应不能算 PASS。
- 显示**官方发布聚合成绩**、**社区发布成绩**、**自采相同样本 Reference**的来源等级，不能将公开总分冒充同题同参数逐样本比较；缺少数据集/评分器/生成参数/样本一致性时仅展示背景参考或不可比。
- 不能以单一总体分数掩盖关键协议失败；不输出未经校准的模型身份概率。
- 禁止把 API Key、原始私有 Prompt、供应商私有地址写进可公开的报告或仓库；原始运行产物默认本地受保护。
- 模型特有规则须以官方文档或固定源码为证据，未知就是 UNKNOWN，不创造规则。
- 不能为检测提供未被官方支持的能力承诺；模型配置需记录核实日期和来源。

## 主要保留与明确不做

**保留**：现有 Go? 否，继续 Python 单项目；本地 Web/CLI、SQLite、HTML/JSON/ZIP 中文报告、基础 HTTP 协议探针、少量有来源的模型规则、lm-evaluation-harness 适配、Kimi 官方测试器（专项）、最小历史对比与证据元数据。

**非目标**：模型权重认证、所有模型的准确身份鉴定、性能压测（TTFT/TPS/RPM）、在线榜单、自动购买官方 API、复杂 Agent、企业 SaaS/多租户、云端调度、GPU 部署、自研庞大题库、自研 Benchmark 评分引擎、多套独立 Web/DB/Reference 管理服务。

可选候选如 proxy-sleuth、promptfoo、fingerprint detector **不成为发布前置依赖**；只在证实有不可替代价值、明确版本与评测有效性时保留，否则移除。不可只凭 README 自称的能力引入。

## 唯一主流程与完成定义

进入本地 Web → 选模型/输入渠道 → 展示档位和预算/依赖 → 检测 → 四段中文报告（协议、能力、异常、证据局限）→ 保存历史/导出/复测。

**自用可用版本完成定义**：五个目标型号均有经过来源核验的配置（某能力可明确 NOT_APPLICABLE/未覆盖）；单个供应商 API 能走通已支持流程；离线 fixture 覆盖真阳性/假阳性/失败/不可比；CI 和安装包检查通过；报告不误导。是否能以统计学意义认定换模**不属于发布条件**。实际渠道性能与质量必须对该渠道实测，离线测试无法替代。
