可信 Reference（Trusted Reference）

用官方 / 高可信端点建立基准，增强“是不是同一个模型”的判断能力。
← 返回模型检测
Reference 最好来自官方端点

例如官方 Kimi、GLM、DeepSeek API。不要把待审计供应商自己当作“可信参考”。

Statistical Fingerprint 很重要

统计指纹会比较目标渠道与 Reference 的行为分布，是当前工具里最强的身份类证据之一。

Reference 也要定期更新

厂商模型、协议或路由发生变化后，旧 Reference 可能失效；建议记录采集时间并按版本更新。
